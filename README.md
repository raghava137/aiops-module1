Q1 is theory only, so it lives in the PDF and has no folder.

### q2

`MLFLOW.ipynb` is the main thing: MNIST with an `MLPClassifier`, six runs
varying learning rate and batch size, everything logged to MLflow. Run it with
a tracking server up on port 5000.

`logging_snippet.py` is the `log_param` / `log_metric` code pulled out on its
own, since the assignment asks for it separately.

`curves.png` and `generalization_gap.png` are generated by the notebook.
`comparision_table_screenshots/` has the MLflow UI comparison view.

MNIST caches to `mnist_cache.npz` on first run. It's gitignored, ~55 MB.

### q3

`make_filelist_csv.py` walks the cats-vs-dogs dataset and writes a CSV of every
filename. That CSV is what's tracked with DVC.

`filelist.csv.dvc` is the pointer. The CSV itself isn't in git, it's in S3.
To get it back you need `dvc pull` with credentials for the bucket.

The screenshot is the rollback: 2801 lines on v2, still 2801 after
`git checkout v1.0`, down to 1801 only after `dvc checkout`. Tags `v1.0` and
`v2.0` mark the two versions.

## Credentials

`.dvc/config` has the bucket URL and is committed. The AWS keys live in
`.dvc/config.local`, which DVC gitignores, so nothing sensitive is in here. If
you clone this you'll need your own credentials to pull the data.

## Running q2 yourself

```bash
mlflow server --backend-store-uri sqlite:///mlflow.db \
    --artifacts-destination ./mlartifacts --serve-artifacts \
    --host 0.0.0.0 --port 5000

export MLFLOW_TRACKING_URI=http://localhost:5000
jupyter lab q2/MLFLOW.ipynb
```

The sweep takes 15 to 40 minutes depending on the machine. Drop `SUBSAMPLE` to
10000 in the first cell if that's too slow.
